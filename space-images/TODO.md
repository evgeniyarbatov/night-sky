# Space Exploration Ideas

## Download Options
- Create a script to bulk download from NASA's APIs (images.nasa.gov has APIs)
- Use `wget` or `curl` to systematically download from these sources
- Set up automated daily downloads from APOD (Astronomy Picture of the Day)

## Exploration Ideas
- Build a local space image gallery/viewer
- Create a Mars rover image tracker using the raw images feed
- Set up RSS feeds from the news sources
- Use NASA's open APIs to get metadata about images
- Create a desktop wallpaper rotator with space images

## Tools you could build
- Space weather monitoring dashboard
- Mars mission image timeline
- Hubble/Webb telescope image comparison tool
- Asteroid/comet tracking visualization
